## Brand & Style

This design system delivers a mission-critical, high-density operational control room interface built for atmospheric data scientists, meteorologists, and computational forecasters. The aesthetic prioritizes absolute precision, zero visual fatigue during prolonged nocturnal operations, and immediate perceptual triage under time-sensitive hazard conditions.

The visual posture is a synthesis of **technical instrumentation minimalism** and **scientific tactical HUD**:
- **Operational Focus**: Deep charcoal and oceanic abyss surfaces suppress extraneous ambient light, directing the operator’s gaze strictly to real-time anomalies and spatial vectors.
- **Instrumental Precision**: Crisp hairline dividers, strict tabular alignment, and calculated mathematical accents replace decorative flourishes.
- **Cognitive Clarity**: Information is stratified into distinct tactical zones—telemetry, ensemble runs, and critical threshold warnings—allowing operators to parse petabytes of atmospheric modeling data without cognitive overload.

## Colors

The palette is engineered around dark-room luminescence. It utilizes an absolute dark foundation to anchor high-contrast analytical data layers:

- **Base Canvas & Layering**:
  - Root Canvas: `#090D16` (Deep Vacuum)
  - Surface Mid: `#0E1526` (Abyssal Navy)
  - Surface Raised / HUD Modules: `#162038` (Atmospheric Marine)
- **Primary & Secondary Analytical Accents**:
  - Primary Vector: `#00F0FF` (Electric Cyan for primary telemetry, cursor vectors, and live sweeps)
  - Secondary Vector: `#00D2C4` (Technical Teal for steady-state data channels and secondary parameters)
- **Model Analysis / Spatial Context**:
  - Tertiary Accent: `#8B5CF6` (Deep Ionospheric Purple for ensemble model layers, ML projections, and assimilation envelopes)
- **Borders & Separation**:
  - Structural Slate: `#1E293B` (Hairline partition default)
  - Active Boundary: `#334155` (Hover, active state, and primary pane delineation)
- **Operational Telemetry & Status**:
  - Validated / Nominal: `#10B981` (Calibrated Emerald Green)
  - Advisory / Divergence: `#F59E0B` (Alert Amber)
  - Critical / Hazard / Anomaly: `#EF4444` (Vivid Crimson)
- **Text & Contrast Hierarchy**:
  - Primary Data Display: `#F8FAFC`
  - Secondary Readouts / Metadata: `#94A3B8`
  - Disabled / Grid Index: `#475569`

## Typography

Typography functions as an analytical instrument. All numerical calculations, coordinates, sensor readings, and model timestamps strictly leverage the monospaced accent font (`JetBrains Mono`) to maintain rigid tabular alignment across dynamic refreshes.

- **Headlines (`Space Grotesk`)**: Technical, clean geometry for system headers, layer titles, and viewport modes.
- **Narratives & Analysis (`Geist`)**: Neutral, highly legible humanist-grotesque for observational descriptions, sync logs, and diagnostic briefings.
- **Data Readouts & Telemetry (`JetBrains Mono`)**: Fixed-pitch character sets ensuring that rapidly updating values do not jitter or break screen layouts. All micro-labels use full uppercase styling with deliberate character spacing.

## Layout & Spacing

The interface employs a dense, modular **fluid grid** calibrated for mission monitoring setups, widescreen multi-monitor arrays, and responsive mobile fieldwork terminals.

- **Desktop (1440px+)**: 12-column or 16-column layout with fixed navigation and status docks. Internal data density utilizes tight `space-xs` and `space-sm` gaps for control clusters and sensor matrix panels.
- **Tablet / Split View (768px - 1439px)**: Dynamic 8-column layout. Analytical panes collapse into collapsible side-drawers or stacked viewport tabs.
- **Mobile Handheld (360px - 767px)**: Single-column data track. Data matrices convert into horizontal-scroll telemetry rows; secondary spatial projections shift to touch-focused overlays with condensed gutters (`0.5rem`).
- **Layout Rhythms**:
  - Standard edge margins scale dynamically: `1.5rem` on enterprise displays down to `0.75rem` on mobile viewport borders.
  - Component packing is tight and uniform, avoiding arbitrary whitespace to ensure maximum analytical payload above the visual fold.

## Elevation & Depth

Visual depth is communicated without muddy dropshadows, avoiding low-contrast blur in operational environments. Hierarchy relies strictly on **tonal containment, luminosity steps, and hairline borders**:

- **Ground Level (Layer 0)**: `#090D16` represents the root application backdrop, world maps, radar scans, and spatial canvas layers.
- **Surface Tier 1 (Layer 1)**: `#0E1526` anchors side docks, telemetry trays, and persistent command bars, framed by a 1px border of `#1E293B`.
- **Surface Tier 2 (Layer 2)**: `#162038` designates tactical overlays, contextual menus, focused card clusters, and parameter inspectors, framed by `#334155`.
- **Active / Scan Accents**: Modals, active telemetry inspectors, and alert banners emit a calibrated, constrained cyan or amber border glow (`0 0 12px rgba(0, 240, 255, 0.15)` or `0 0 12px rgba(239, 68, 68, 0.2)`), signaling interactive readiness or critical threat levels without occluding underlying map vectors.

## Shapes

The design system employs **compact, precision-machined geometry** (Soft roundedness: `0.25rem` / `4px`). 

- Default elements (input fields, buttons, tabular cells, and card containers) utilize crisp `0.25rem` corners.
- Larger tactical frames and dashboard cards scale to `0.5rem` (`rounded-lg`) maximum to preserve a rigorous, scientific instrument architecture.
- Full pill radii are reserved strictly for high-priority live indicators (e.g., streaming pulse indicators or circular status beacons).

## Components

### Buttons
- **Primary / Execute**: Background `#00F0FF`, text `#090D16` (`JetBrains Mono`, bold, all-caps). On hover: `#00D2C4` with a subtle technical bloom. Active state scales down slightly (`0.98`).
- **Secondary / Tactical**: Background transparent, border 1px solid `#334155`, text `#F8FAFC`. On hover: border `#00F0FF`, background `rgba(0, 240, 255, 0.05)`.
- **Destructive / Abort**: Background `rgba(239, 68, 68, 0.12)`, border 1px solid `#EF4444`, text `#EF4444`.

### Data Chips & Status Badges
- **Format**: Ultra-compact padding (`0.125rem 0.375rem`), font `label-sm` (`JetBrains Mono`, tracking +0.08em).
- **Nominal / Calibrated**: Background `rgba(16, 185, 129, 0.1)`, border 1px solid `#10B981`, text `#10B981`. Includes a leading 4px static dot.
- **Divergence / Warning**: Background `rgba(245, 158, 11, 0.1)`, border 1px solid `#F59E0B`, text `#F59E0B`.
- **Critical / Anomaly**: Background `rgba(239, 68, 68, 0.15)`, border 1px solid `#EF4444`, text `#EF4444`. Pulsing dot indicator.
- **Model Context Tag**: Background `rgba(139, 92, 246, 0.12)`, border 1px solid `#8B5CF6`, text `#C4B5FD`.

### Data Tables & Sensor Lists
- Headers use `label-sm`, text `#94A3B8`, anchored over `#0E1526` with a bottom border of 1px solid `#1E293B`.
- Data rows alternate subtly on zebra striping or maintain hairline separator lines (`#1E293B`).
- All numeric readouts use `tabular-md` or `tabular-lg`, strictly right-aligned with physical metric units (`hPa`, `m/s`, `dBZ`, `°C`) styled in `#475569`.

### Form Controls (Inputs, Selectors, Checkboxes)
- **Inputs**: Background `#090D16`, border 1px solid `#1E293B`, text `#F8FAFC`, font `tabular-md`. Focus ring: 1px `#00F0FF` with no native browser outline.
- **Checkboxes & Radios**: Square / hexagonal footprint, 14px size, border 1px solid `#334155`. Checked state fills `#00F0FF` with `#090D16` icon marker.

### Cards & HUD Modules
- Containers built on `#0E1526` with hairline `#1E293B` outlines.
- Optional HUD corner-tick styling or technical module headers with top status lines (1px cyan bar indicator when panel data is actively streaming).

### Domain-Specific HUD Elements
- **Ensemble Run Slider**: High-density horizontal scrubber with labeled epoch ticks (`+00h`, `+06h`, `+12h`, etc.), dynamic purple assimilation bracket overlays (`#8B5CF6`), and cyan scrubber pin.
- **Vector Coordinate Chip**: Compact dual-coordinate readouts (`LAT/LON`) with integrated copy/lock actions.
